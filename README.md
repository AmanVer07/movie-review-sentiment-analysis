# movie-review-sentiment-analysis
NLP-based sentiment analysis of movie reviews using text preprocessing and machine learning techniques.

# Movie Review Sentiment Analysis

## Overview
An NLP-based machine learning project that classifies movie reviews
as positive or negative.

## Technologies
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn

## ML Techniques
- Text preprocessing
- Tokenization
- Stopword removal
- TF-IDF
- Classification
- Model evaluation

## Models
- Logistic Regression
- Naive Bayes
- Random Fores

## Evaluation
Accuracy, Precision, Recall, F1-score and Confusion Matrix.
